# Лабораторная работа 1

Gavrishok Nikolai

Модель предсказывает, получит ли пост меньше, примерно столько же или больше
реакций, чем обычно получает его автор. Используются текст, история реакций,
длина публикации и активность автора. Изображения и видео не нужны.

Вычислительная тетрадь: `lab1_gavrishok_nikolai.ipynb` в корне репозитория.
Она показывает сохранённые результаты и позволяет повторить обучение.

## Запуск

Команды выполняются из корня репозитория. Проверенное окружение: Python 3.13.7;
версии библиотек указаны в requirements.txt этой папки. Нужны полные папки
posts/ и authors/, а также labels.csv и split.json. Данные в ветку не включены.

```powershell
python -m pip install -r submissions/gavrishok-nikolai/requirements.txt
python solution_gavrishok_nikolai.py --data "D:/kairos/data" --out results/gavrishok-nikolai --final
python evaluate.py --data "D:/kairos/data" --predictions results/gavrishok-nikolai/predictions.csv
```

Путь D:/kairos/data нужно заменить на свой. Готовые предсказания можно проверить так:

```powershell
python evaluate.py --data "D:/kairos/data" --predictions submissions/gavrishok-nikolai/predictions.csv
```

## Метод

Официальное разделение по авторам сохранено. Для сравнения вариантов внутри
обучающей части отложены 20% авторов. Эта часть дополнительно разделена пополам:
на одной половине уточняются веса моделей, на второй проверяется результат.

Проверены два изменения: более точный подбор весов и новые признаки автора.
Новые признаки показывают, насколько длина поста и перерыв перед ним отличаются
от обычных у автора, а также сколько постов он опубликовал за последние 7 и 30 дней.
Выбран вариант с новыми признаками. Итоговая смесь состоит на 80% из числовой
модели и на 20% из текстовой; веса классов — 0.8, 1.0, 0.8.

Реакции текущего поста не используются как признак. История рассчитывается
по предыдущим публикациям. Число подписчиков и возраст поста относятся к моменту
сбора, как в исходном примере, что ограничивает перенос оценки на будущие посты.

`report.json`. В `predictions.csv` находятся предсказания для всех проверочных постов.
